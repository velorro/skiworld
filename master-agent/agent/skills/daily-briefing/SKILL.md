# Daily briefing

Produce a briefing Rick can skim in under 60 seconds.

## Steps

1. Calendar (`America/Denver`): today + tomorrow. Note conflicts and interview-shaped events.
2. Gmail `Action`: list threads that still need Rick.
3. Gmail `Job Apps`: new confirmations, declines, or interview logistics since last brief.
4. Gmail `Waiting On`: anything older than 7 days — propose a nudge draft.
5. Recommend **one** focus block for the day (role targeting, follow-ups, or interview prep).

## Output format

```
## Brief — <day, date MT>
**Focus:** <one sentence>
**Calendar:** ...
**Action (n):** ...
**Job Apps:** ...
**Waiting On (>7d):** ...
**Suggested next move:** ...
```

Do not dump full email bodies. Link/thread IDs only when useful.
