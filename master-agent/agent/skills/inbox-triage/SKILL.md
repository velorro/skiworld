# Inbox triage

## Goals

- Zero mystery in the inbox.
- Everything either Action, Waiting On, Job Apps, FYI, Personal, Travel, Receipts, or trash/spam.

## Procedure

1. Scan Inbox + unread Important.
2. For each thread, choose **one primary label** (Job Apps wins for application mail).
3. If Rick must reply → `Action` + draft reply in his voice (concise, professional).
4. If waiting on someone else → `Waiting On` + note the expected next event.
5. Marketing / noise → propose archive; do not delete unless clearly spam.
6. Security codes / OTPs → surface immediately at the top; never store codes in long-term notes.

## Hard rules

- **Do not send** mail unless Rick explicitly approves the draft.
- Prefer `create_draft` / draft tools over send.
- Never mark Job Apps threads as FYI if they still need tracking — update the pipeline doc instead.
